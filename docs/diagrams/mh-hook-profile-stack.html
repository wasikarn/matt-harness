Tier is a volume knob, not a severity — and one path ignores it

29 enforcement points across two tables. 18 live in hooks.json; 17 of those route through dispatch-single.sh, where tier sets the minimum MH_HOOK_PROFILE at which a handler fires — lowering the profile peels layers off the top, so "strict" is the first thing a profile change switches off, not the strongest enforcement.
