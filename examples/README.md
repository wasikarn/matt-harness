# examples/ — project-type CLAUDE.md starters

Copy a starter into a new repo as its `CLAUDE.md`, fill the `<PLACEHOLDERS>`, delete the top note.
Borrowed pattern from ECC's `examples/` (project-type templates), trimmed to kbg's scale.

**Reference only** — not auto-discovered, not a plugin-delivered surface, not loaded into any session.
The files are named `*-CLAUDE.md` (not `CLAUDE.md`), so Claude Code never picks them up automatically.

| Starter | Use for |
|---|---|
| `tathep-service-CLAUDE.md` | a backend service in the TaThep Platform (TP-* tickets, Thai PO/QA AC) |
| `personal-project-CLAUDE.md` | a solo / personal repo (lean, single-author) |

Keep starters short — `CLAUDE.md` is read every session, so bloat costs context every turn.
