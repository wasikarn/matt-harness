## Mode: probe

Systems-thinking analysis *before* committing to a frame. Use when the diagnosis
itself is contested or the problem space is complex/emergent.

1. Map the system: actors, flows, feedback loops, delays (catalog entry:
   `docs/reference/thinking-skills/skills/thinking-systems/SKILL.md` — read via Bash, `cat
   "${KBG_PLUGIN_ROOT}/docs/reference/thinking-skills/skills/thinking-systems/SKILL.md"`).
2. Name the leverage points — the highest-impact spots to intervene (catalog entry:
   `docs/reference/thinking-skills/skills/thinking-leverage-points/SKILL.md` — read via Bash, `cat
   "${KBG_PLUGIN_ROOT}/docs/reference/thinking-skills/skills/thinking-leverage-points/SKILL.md"`;
   the bare repo-relative path resolves nowhere in a foreign-project CWD).
3. Stress-test the diagnosis: what would prove the current frame wrong? Cross-check
   against every actor named in step 1's map, not just the theories already on the
   table — a stated diagnosis only covers who spoke up, and the map often holds an
   unclaimed candidate cause nobody's blaming yet.
4. Output: a framing memo, not a decision — hand off to `decide` or `strategize`.
